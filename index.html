Below you can find the technologies powering this portfolio :

  1. Amazon S3: Hosts the static front-end web files (HTML, CSS, JavaScript, and game assets).
  2. AWS CloudFront: Content Delivery Network (CDN) providing global edge caching, fast distribution, and low latency.
  3. AWS Certificate Manager (ACM): Provisioned and managed the free SSL/TLS security certificate required for secure HTTPS communication.
  4. Amazon Route 53 / Checkdomain DNS: Manages custom domain name routing, records, and redirects to map traffic seamlessly to the CloudFront distribution.
  5. Amazon API Gateway: Managed REST API endpoint routing HTTP requests securely between the browser and backend.
  6. AWS Lambda: Serverless Python function execution layer handling visitor counter increments, real-time suggestion box submissions, and high-score submissions.
  7. Amazon DynamoDB: Fully managed NoSQL database storing persistent visitor analytics, user suggestions, and high-score records.
  8. Amazon Bedrock (Nova Micro): Powers intelligent backend features, including generative AI-driven responses and dynamic elements within the (AI-)Gorilla game (Trash-Talk), or the cheerful AI-Companion Project.
  9. Google Gemini API: Drives generative AI features, dynamic text synthesis, and intelligent assistant workflows.
  10. Google Places API: Handles location data lookups, addresses, and geographic context for real-world integration.
  11. Microsoft Azure Speech: Synthesizes natural-sounding voice audio to read out the AI-generated text responses.
  12. Amazon SES (Simple Email Service): Handles automated transactional emails or notification deliveries triggered from backend events.
  13. AWS CloudWatch: Monitors application logs, Lambda performance, and operational health metrics.
  14. AWS CloudShell: Used for browser-based command line management, deployment scripts, and interacting with AWS resources.
  15. JavaScript (ES6+) Modules: Powers modular component logic, clean script structure, and dynamic UI rendering using native imports and exports.
  16. HTML5 Canvas & CSS3: Renders interactive arcade game mechanics, fluid layouts, and modern visual styling.
  17. Asynchronous REST / Fetch API: Manages seamless, asynchronous client-server communication between the browser frontend and AWS API Gateway endpoints.
