Music Lab

Beta
Built with HTML5 · CSS3 · JavaScript · Web Audio API · abcjs · jsPDF · svg2pdf.js · HTML5 Canvas · Modular ES6

An interactive web-based music composition and playback studio for Cello and Piano. Built with vanilla JavaScript and a modular architecture, it lets users write, transpose, and play back scores in real time using abcjs and the Web Audio API. It features dynamic measure tracking, note-pads with custom durations and accidentals, live canvas frequency visualizations, classical presets, and tools to export compositions as high-resolution PDFs or WAV audio files.

Kitchen Byte

In Development
Built with HTML5 · CSS3 · JavaScript · Google Gemini API · Google Places API · Modular ES6

An interactive AI-powered global meal-prep agent and zero-waste menu planner. Built using vanilla JavaScript and modular ES6 architecture, it coordinates the Google Gemini API to generate tailored multi-day recipes, calorie breakdowns, and aisle-grouped grocery lists based on custom dietary preferences, household sizes, and fitness goals. It also integrates the Google Places API to look up nearby supermarket addresses and operating hours using postal codes, and features drag-and-drop or tap-to-select meal swapping with full printable recipe guides.
