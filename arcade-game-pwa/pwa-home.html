How to install the App

×

On iOS (Safari/Chrome):

1. Tap the Share button at the bottom
(Chrome on top).

2. Tap View More.

3. Find and tap "Add to Home Screen" .

On Android (Chrome):

1. Tap the three-dot menu ⋮ in the top right.

2. Tap "Install app" or "Add to Home screen".

On Desktop:

Google Chrome:

1. Click the three-dot menu ⋮ in the top right.

2. Select Cast, save, and share →

3. Select Install page as app.

Microsoft Edge:

1. Click the three-dot menu ⋯ in the top right.

2. Select More tools →

3. Select Apps →

4. Select Install this site as an app.

Have a favorite game? You can use these same steps on that game's own page to add just that game to your home screen as its own app.
